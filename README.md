# ⚡ WattWise

Smart Electricity Bill Estimator Mobile Application

## 📱 Project Overview

WattWise is a mobile application developed for ICT602 Mobile Application Development.

The application helps users estimate their monthly electricity bills based on:

- Electricity usage (kWh)
- Rebate percentage
- Current tariff rates

Users can:

- Landingpage
- Calculate electricity bills
- Save bill records
- View bill history
- Edit records
- Delete records
- Manage electricity usage efficiently
